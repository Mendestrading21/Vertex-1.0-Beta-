# Checklist avant une PR

- [ ] Diff limité au lot annoncé et sans fichier généré inutile.
- [ ] Objectif et non-objectifs respectés.
- [ ] Lint, format, types, tests, build et migrations applicables verts.
- [ ] OpenAPI, JSON Schema et client généré synchronisés.
- [ ] Tests de propriétés/référence ajoutés si finance touchée.
- [ ] États partiel, retardé, périmé, offline et erreur testés si source/UI touchée.
- [ ] Aucun ordre, compte, position, exécution ou scraping introduit.
- [ ] Secret scan, vulnérabilités, licences et provenance contrôlés.
- [ ] Captures 1280×800, 1440×900, 1600×1000 et dégradation laptop 1024×768 sans donnée personnelle si UI touchée ; aucune capture mobile Beta.
- [ ] Documentation, ADR, registre des calculs et `NOW.md` mis à jour.
- [ ] Risques et limites restants écrits explicitement.
- [ ] Une seule prochaine commande proposée ; aucune fusion réalisée.
