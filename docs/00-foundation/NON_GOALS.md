# Non-objectifs de Vertex 1.0

Ces exclusions protègent la cohérence du produit. Elles ne sont pas un backlog implicite.

- envoyer, modifier, annuler, exercer ou prévisualiser un ordre ;
- importer automatiquement comptes, soldes, positions, P&L, ordres ou exécutions IBKR ;
- reproduire l'interface complète de TWS ou TradingView ;
- contourner un abonnement, une limite API, un droit de redistribution ou une mesure anti-bot ;
- aspirer les interfaces web TWS, TradingView, sites d'actualité ou relations investisseurs ;
- faire du trading à haute fréquence, du market making ou une promesse de rendement ;
- produire un signal autonome non explicable ou une probabilité non calibrée ;
- laisser l'IA générer une décision, une valeur de marché ou un calcul financier ;
- construire une plateforme multi-utilisateurs publique, un réseau social ou une place de marché ;
- fournir comptabilité fiscale, conformité réglementaire ou conseil financier personnalisé ;
- synchroniser l'ancien Vertex ou reprendre son historique Git ;
- adopter microservices, Kubernetes, GraphQL, Redis, Celery, TimescaleDB ou une app desktop sans mesure et ADR ;
- stocker dans Git des données réelles, secrets, identifiants de compte ou exports personnels.

Une modification de cette liste exige une décision humaine et un ADR. Les capacités IBKR interdites exigent en plus une nouvelle analyse de menace ; Claude ne peut pas les rouvrir seul.
