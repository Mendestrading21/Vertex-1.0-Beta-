# Glossaire canonique

| Terme | Définition obligatoire |
|---|---|
| Observation | Valeur reçue d'une source, immuable et horodatée |
| Snapshot | Vue cohérente d'un ensemble d'observations à un instant donné |
| Fresh | Assez récente pour l'usage défini |
| Delayed | La source annonce explicitement un retard |
| Stale | L'âge dépasse le TTL de l'usage |
| Partial | Certains champs ou instruments requis manquent |
| Invalid | Échec de schéma, unité, bornes ou cohérence |
| Gate | Règle déterministe qui autorise, dégrade ou bloque un calcul/conseil |
| AdviceResult | Unique verdict canonique, versionné et traçable |
| Estimé | Dérivé d'hypothèses non directement observées |
| Théorique | Produit d'un modèle, pas d'une exécution historique |
| Simulé | Résultat d'un scénario défini et reproductible |
| Réalisé | Résultat issu du ledger manuel confirmé |
| Probabilité risque-neutre | Distribution implicite de prix sous mesure de valorisation |
| Fréquence historique | Proportion empirique d'un événement dans un échantillon défini |
| Probabilité prédictive | Estimation physique calibrée et testée hors échantillon |
| GEX | Estimation d'exposition gamma dépendante d'une hypothèse de positionnement |
| Point-in-time | Donnée telle qu'elle était réellement connaissable à la date étudiée |
