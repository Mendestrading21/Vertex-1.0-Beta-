# Prompt — valider un profil de stratégie

Travaille en mode Plan sur `PROFILE_ID@VERSION`.

- valider le JSON Schema et les unités ;
- vérifier que les paramètres personnels restent locaux ;
- vérifier instruments, horizon, DTE, delta, liquidité, événements et perte
  maximale ;
- prouver toutes les données au temps de décision ;
- construire baseline, walk-forward purgé, calibration et tests de drift ;
- tester abstention, contradiction, données rassises et source non autorisée ;
- interdire ordre, vente nue, probabilité non calibrée et signal social seul ;
- conclure `DRAFT`, `VALIDATED`, `SHADOW` ou `REJECTED`, sans activer le profil.
