# Contribution

- Un lot, une branche, une PR.
- Lire `CLAUDE.md` et la constitution.
- Aucun élargissement silencieux de périmètre.
- Les changements de contrats, calculs, intégrations ou sécurité nécessitent tests et ADR si la décision change.
- Les fixtures sont synthétiques et sans données personnelles/licenciées.
- Les PR listent commandes, résultats, captures, migrations, risques et rollback.
- Merge humain uniquement après tous les checks requis.
